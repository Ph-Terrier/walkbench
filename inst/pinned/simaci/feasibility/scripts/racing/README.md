## How SIM-ACI uses it

`scripts/00_functions_walker.R` loads this file into its own environment and calls two of its documented top-level functions on the 4-D model state `[thG, thGd, phG, phGd]`:

- `find_nearest_neighbors(Y, mean_period)` with `mean_period` = one stride (samples), the Theiler window;
- `compute_divergence(Y, nearest_pos, max_iter)` with `max_iter` = four steps (samples).

RACING's own entry point, `rosenstein_divergence()`, is not called because it delay-embeds a univariate signal, whereas the model state is observed directly (no embedding, as in Su & Dingwell 2007). The initial separation (k = 0), the smoothing and the instantaneous slopes that give lambda_S and lambda_L are SIM-ACI code. At load time the adapter checks the MD5 above and warns if the file has been altered.
